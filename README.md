**把收入、支出、儲蓄與人生目標放在同一張財務地圖上。**

錢路是一套免費、純本機的繁體中文個人理財工具，整合記帳、多帳戶管理、每月資金分配、儲蓄率分析，以及房貸、學貸、買房、旅行與退休試算。資料只需輸入一次，各項結果便會自動連動；不需註冊、不依賴 AI，也不會把財務資料傳到伺服器。

> 適合想知道「每月能存多少、每天能花多少、目標何時達成」的人。

## 一眼看懂

| 你想知道的事 | 錢路提供的答案 |
| --- | --- |
| 每月的錢該怎麼分？ | 自動整理固定支出、應儲蓄、每日生活費與額外可用資金 |
| 現在的儲蓄狀況健康嗎？ | 計算儲蓄率、目標達成率，指出做得好的地方與待改善項目 |
| 多份工作與多個帳戶怎麼管理？ | 合併正職、兼職、接案收入，再依帳戶用途分配資金 |
| 買房、還學貸或退休需要多少錢？ | 試算總成本、通膨、月繳、資金缺口與預計達成時間 |
| 一個目標等於多少工時？ | 由薪資、工時與勞健保設定反推時薪、班次、週數及月數 |
| 資料會不會外流？ | 所有計算與保存均在瀏覽器本機完成，不需帳號或雲端服務 |

## 主要功能

- **本月總覽**：快速查看月收入、固定支出、每月應儲蓄、每日生活費和月度餘裕。
- **智慧資金分配**：先安排基本生活、固定支出與緊急預備金，再分配至選定目標和指定帳戶。
- **簡單記帳**：記錄收入、支出、轉帳與固定儲蓄；自動統計分類月均花費和占比。
- **帳戶核對（不逐筆記帳）**：月初把錢存進各用途帳戶後，只要定期填各帳戶餘額、想到再加備註；工具依固定出入帳計畫推算每段期間用掉多少。和逐筆記帳可以並存，並可設定開啟帳本時先顯示哪一種。
- **多收入管理**：支援正職、兼職與接案；各收入可獨立設定發薪日、入帳帳戶及是否扣勞健保。
- **多帳戶管理**：自訂帳戶名稱、用途和起始餘額，轉帳不會被誤算成收入或支出。
- **目標與成本試算**：內建買房、買地自建、學貸、旅費、喪葬費、養老金與 FIRE 退休情境，也能新增或複製情境。
- **貸款規劃**：估算房貸與學貸的月繳、年限、利息、寬限期及壓力情境，並可納入固定支出。
- **工時反推**：用月薪和月工時回算時薪與估計實領，再計算達成目標所需工時。
- **結論／編輯模式**：結論模式只看關鍵結果；需要調整時再切換完整編輯畫面。
- **本機自動保存**：修改後立即保存，最多保留 20 個滾動版本，也可綁定 JSON 工作區檔案。

## 安裝（Windows／Mac）

錢路不需要安裝程式，也不需要 Node.js：下載專案後用瀏覽器開啟 `index.html`。要把工作區綁定到本機 JSON 檔案，請用最新版 Chrome 或 Edge；Safari、Firefox 只能保存在瀏覽器本機並用匯出備份。

**下載 ZIP（最簡單）**：在 GitHub 專案頁按 **Code → Download ZIP**，解壓縮後把資料夾改名為 `MoneyPath`，移到「文件」資料夾，雙擊 `index.html`（建議建立桌面捷徑）。

**使用 Git（方便更新）**：

```powershell
# Windows PowerShell
Set-Location ([Environment]::GetFolderPath('MyDocuments'))
git clone https://github.com/moneypath-tw/finance-tools.git MoneyPath
Start-Process .\MoneyPath\index.html
```

```bash
# Mac 終端機
cd ~/Documents && git clone https://github.com/moneypath-tw/finance-tools.git MoneyPath && open MoneyPath/index.html
```

之後在 `MoneyPath` 資料夾執行 `git pull` 即可更新。

| 用途 | Windows | Mac |
| --- | --- | --- |
| 網頁入口 | `C:\Users\<你的帳號>\Documents\MoneyPath\index.html` | `~/Documents/MoneyPath/index.html` |
| 建議的個人備份檔 | `C:\Users\<你的帳號>\Documents\MoneyPath Data\money-path-workspace.json` | `~/Documents/MoneyPath Data/money-path-workspace.json` |

- 個人工作區 JSON 請放在專案外的 `MoneyPath Data`，不要放進 `MoneyPath` 公開程式碼資料夾，避免被 Git 誤提交。
- 「文件」由 OneDrive 或 iCloud Drive 同步時，檔案可能上傳雲端；要嚴格留在單機，請改放未同步的本機資料夾。

## 第一次使用

1. 開啟 `index.html`，進入「帳本」設定出生年份、固定收入與帳戶。
2. 設定每月固定支出、固定儲蓄與入扣款日期；已知金額會自動連動。
3. 回到「首頁」查看每月分配、儲蓄率、每日生活費與財務健檢。
4. 到「成本試算」建立買房、學貸、旅行或退休目標。
5. 在首頁選擇本機保存位置，建立或綁定 `money-path-workspace.json`。

不必先整理完整帳本。只有收入與支出，也能立即得到每月結餘、儲蓄率和每日可用生活費。

## 設計原則

- **輸入一次，全站連動**：優先沿用已有資料，自動推導可計算的數值。
- **先看結論，再看細節**：預設突出行動所需的關鍵數字，進階公式可自行展開。
- **公式透明，不靠 AI**：純前端 JavaScript 計算，可離線使用、測試與核對。
- **資料留在本機**：不設後端、不需登入，也不連接真實銀行帳戶。
- **低維護、可長期使用**：制度與利率採有日期的參考快照，重要參數皆可手動調整。

## 資料保存與備份

- 最新工作資料保存在目前瀏覽器設定檔的 `localStorage`，滾動版本保存在 IndexedDB。
- 修改、切換背景、關閉分頁或離開頁面時，系統會嘗試自動保存；右下角顯示最後成功保存時間。
- 可在首頁選擇或建立 JSON 工作區檔案。授權有效時，修改內容會同步寫入該檔案。
- 匯入的原始檔不會被移動或改寫；匯出的 JSON 會進入瀏覽器設定的下載位置。
- 清除網站資料、更換瀏覽器設定檔或重灌瀏覽器可能移除本機資料，請定期匯出 JSON 備份。Safari（含 iPhone、iPad）長時間未開啟網站時可能自動清除網站資料，線上版在 Safari 上更要定期匯出。
- 綁定工作區檔案需要 Edge 或 Chrome；Firefox、Safari 只會保存在瀏覽器本機，請用匯出備份。
- 線上版的離線快取（`sw.js`）只存放程式檔，不存放財務資料；有網路時一律先取最新程式。
- 公開倉庫只應存放程式碼與範例假資料；真實財務資料請留在本機或私密倉庫。

## 計算方式與重要界線

- 所有金額以整數「分」儲存與計算，避免小數誤差；帳戶核對紀錄存在帳本的 `snapshots` 欄位，舊資料沒有這個欄位也能照常讀取。
- **通膨一律複利**：`今日金額 × (1 ＋ 年通膨率)^(月數 ÷ 12)`。財務健檢、成本試算與養老金用同一公式；月數算到首頁為該目標設定的月份（養老金算到退休年齡）。年通膨率依地區採各國央行官方預測：台灣用中央銀行、日本用日本銀行、歐元區用歐洲中央銀行，可在介面覆寫。
- **緊急預備金**＝每月（必要固定支出＋基本生活開銷）× 目標月數，**不扣任何補助**（補助可能停發）；首頁分配、財務健檢與 FIRE 連動都用同一算法，每月補足額為缺口 ÷ 12。
- **每月可存**＝固定收入－固定支出－生活開銷；成本試算的「存款版達成時間」與 FIRE 連動都用這個數字。
- **FIRE** 退休前總需求＝退休資產目標＋其他目標＋緊急預備金。開啟連動時，目前年齡、月薪、月支出、已存資產、其他目標（首頁勾選的成本目標）與緊急預備金都由帳本與首頁帶入。
- 勞保費率含就業保險（受僱者負擔 20%），健保以本人計算、未含眷屬，也未套投保薪資分級表；實際以投保單位計算為準。
- 實質報酬率：`(1 ＋ 名目報酬率) ÷ (1 ＋ 通膨率) − 1`。財務健檢同時提供有利、基準與壓力情境；壓力情境包含收入下降、較高通膨和零投資報酬。
- 帳戶核對的「用掉」是推算值：`期初餘額 ＋ 期間內計畫存入 − 期末餘額`，計畫存入來自固定出入帳（收入入帳、儲蓄轉入減轉出）。帳戶互轉不記錄時，個別帳戶會一邊多花、一邊多存，但全部帳戶加總不受影響，所以總覽以加總為主；結果為負時顯示「多出」（利息、退款、計畫外收入）。核對間隔不固定，比較各期時看「每 30 天」換算值。
- 本工具自訂的規劃規則（儲蓄率基準與健康分級、緊急預備金月數範圍）只定義在 `shared/config.js` 的 `PLANNING_RULES`。
- **外部數字的唯一來源**是 `shared/reference-data.js`：每筆都附官方機關網址與取得日期（通膨預測、勞保與就保費率、健保費率、學貸利率、房貸利率），測試會擋下沒有官方來源或日期的項目。更新數字只改這個檔案。
- 試算結果取決於輸入與假設，不代表收益保證，也不構成投資、稅務、保險、法律或貸款建議。

## 隱私防護

首次複製專案後，建議啟用提交前的隱私掃描：

```powershell
git config core.hooksPath hooks
```

本機 hook 與 GitHub Actions 都會執行 `scripts/check-no-real-data.sh`，發現疑似真實財務資料時阻止提交或標記檢查失敗。

線上版的防護與限制：

- 網址放在專用的 `moneypath-tw.github.io`，不與其他專案共用網域，其他網站讀不到錢路存在瀏覽器裡的資料。
- `index.html` 的 CSP 設定 `connect-src 'none'`，頁面無法對外發出連線；`shared/frame-guard.js` 阻止其他網站用 iframe 嵌入錢路誘導點擊。
- 線上版每次開啟都載入倉庫最新的程式，安全性取決於本倉庫與發布帳號沒有被入侵；想完全排除這個風險，請改用下載版並固定版本。
- 發現資安問題請見 [SECURITY.md](SECURITY.md)。

## 開發與測試

程式結構、各數字的唯一來源與計算管線見 [設計架構與計算邏輯](docs/設計架構與計算邏輯.md)。

本專案無第三方執行期套件，使用 Node.js 內建測試器（測試同時編譯 `index.html` 載入的每支腳本與 `sw.js`）：

```powershell
npm test
```

測試涵蓋通膨、實質報酬、財務健檢、壓力情境、緊急預備金、帳本驗證、外幣匯率、FIRE、目標推算、外部數字來源及多項邊界條件，以及線上版的攻擊面回歸測試（惡意匯入、HTML 注入點、CSP 不允許行內樣式、多分頁互相覆蓋、離線快取範圍）。

改動到保存、離線快取或頁面載入時，另跑瀏覽器實測（需本機有 Chrome，不需網路；會載入舊版存檔確認轉換正確）：

```powershell
npm run browser-check
```

GitHub Actions 會執行測試與隱私掃描。
